📦 viztral Deploy From

Deployment Repository

Mirror of the compiled dist/ files. Serves the active domain via GitHub Pages. Do not edit source files here.

How to manage updates:

  • To update text, layouts, or assets: Modify files under the /Users/ravikuruganthy/myApps/website directory. You can test your changes locally using npm run dev inside that directory.
  • To deploy changes live: Run npm run build inside the website directory, copy the built assets to this viztral folder, and push it to GitHub (as outlined in the steps below).
1
Switch to Source & Build

Go to the local source code folder and run the Vite compiler to bundle your React website. This creates a fresh dist/ folder containing production-ready assets.

cd /Users/ravikuruganthy/myApps/website && npm run build
2
Copy Build Assets to Deployment Repo

Copy all compiled assets (HTML, CSS, JS, and logos) into your deployment directory, overwriting the old static assets.

cp -R /Users/ravikuruganthy/myApps/website/dist/* /Users/ravikuruganthy/myApps/viztral/
3
Push Code to GitHub (Triggers Pages Deploy)

Navigate to the deployment workspace, commit the newly copied files, and push them to the GitHub main branch. This triggers GitHub Pages to publish changes live to viztral.ai.

cd /Users/ravikuruganthy/myApps/viztral && git add . && git commit -m "Deploy latest updates" && git push origin main
⚡
Important DNS Safety: Your DNS management resides in AWS Route 53 (not GoDaddy) to prevent your AWS app (app.viztral.ai) from going down. Do not change nameservers at GoDaddy.
